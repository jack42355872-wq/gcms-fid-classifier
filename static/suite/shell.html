從上方選單切換工具。開過的工具會留在背景，正在編輯的數據、勾選和圖都維持原樣。除了 FID 分類，其餘六個工具的數據都存在這個瀏覽器裡，關掉頁面再打開會自動還原。

資料備份

反應器、GC-TCD、液相 ASF、液相回收率、層析圖排版、L16 六個工具的數據只存在這個瀏覽器。換電腦、換瀏覽器或清除網站資料之前，先匯出一份備份；之後在這裡匯入，就能把六個工具一起還原。（FID 分類不在瀏覽器存資料，每次上傳即時分析，不需備份。）

備份包含各工具的設定、峰表、已存的數據、圖片樣式、疊圖與組圖排版，反應器記錄的分段與選取，以及液相回收率填的反應條件、冷阱條件與碳數分佈。反應器的原始 CSV 檔案太大，不放進備份，請保留原檔。

關於這個工作區（2026-10-18 整合）

  • 來源。反應器記錄分段、GC-TCD、液相 ASF、層析圖排版、L16 最佳化這五個工具原本是學長做的獨立網頁（只能在 claude.ai 裡開），現在和 FID 分類放進同一個站。工具本身的程式沒有重寫，只改了這幾處：下載改成一般瀏覽器下載、數據存放改接這裡的共用儲存、液相 ASF 的類別判定順序（見下一條）、ASF 載入只有「Sheet1」一個工作表的檔案時改用檔名當樣品名、反應器記錄找不到範例檔時的提示。
  • FID 分類與液相 ASF 的分工。FID 分類是依化學結構規則把每個峰歸入 7 大類（含 n-alkane 的滯留時間校驗），輸出各類百分比與 Excel 報告；液相 ASF 是依名稱與滯留時間指派碳數，求 Total / Alkane / Alkene 的碳數分布與 α。液相 ASF 原本先判環、再判不飽和，環烯（cyclopentene、cyclohexene 等）會被算成 cyclic；已改成「含氧／雜原子 → 芳香環 → 不飽和 → 環 → 烷」，和 FID 分類同一套順序，cyclic 只收全飽和的環。但 FID 分類另外用滯留時間校驗 n-alkane（名稱是直鏈烷、RT 卻對不上標尺的歸 iso-alkane），ASF 沒有這一步，所以同一份峰表的 n-alkane／iso-alkane 比例兩邊仍會有差；溶劑峰的扣除規則也不同。要出 i/n 比，以 FID 分類為準。
  • 液相回收率計算（2026-11-02 加入）。學長另外做的第六個工具：用 Peng–Robinson 狀態方程式算冷阱閃蒸，估計 C₅₊ / C₈₊ 有多少進到液相、多少隨尾氣走掉；填實際收油可得收集效率 η，貼液相碳數分佈可校正 α。程式原樣放入，只把它存設定的 localStorage 改接這裡的共用儲存（所以備份收得到）。它的輸入大多來自前面的工具，目前要手動帶：轉化率與 CO、CH₄、C₂₋₄ 選擇性看 GC-TCD，α 看液相 ASF。算出來的是平衡模型的估計值，不是量測值。
  • 範例資料。液相 ASF（13 個樣品）、層析圖排版（6 條 TIC）、L16（範例數據）首次開啟時會帶學長原檔附的示範數據，載入自己的檔案後會取代。反應器記錄沒有附範例檔，請直接拖入記錄器 CSV。
  • 隱私與費用。整個站沒有任何 AI／Claude 的呼叫（伺服器沒有 API 金鑰，頁面也不連任何模型服務），使用不會消耗 token。六個工具全部在你的瀏覽器裡計算，檔案不會上傳到伺服器；它們需要的三個函式庫（Excel 讀寫、繪圖）也是由本站直接提供，不依賴外部 CDN。FID 分類會把檔案送到伺服器處理，處理完即丟棄、不存檔；僅對辨識不出的化合物名稱向 PubChem 查詢（只送名稱，不送濃度或檔案）。
